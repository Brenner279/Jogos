# 🧮 Desafio Matemático

Um jogo simples, rápido e divertido feito com HTML, CSS e JavaScript puro (Vanilla JS). O objetivo é resolver o maior número de equações matemáticas geradas aleatoriamente (adição, subtração e multiplicação).

## 🚀 Funcionalidades
- Contas geradas aleatoriamente.
- O sistema evita resultados negativos na subtração.
- Sistema de pontuação: +10 pontos por acerto, -5 pontos por erro.
- Design responsivo e moderno.
- Suporte para uso da tecla "Enter" para enviar respostas.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura da página.
- **CSS3:** Estilização, Flexbox, gradientes e sombras.
- **JavaScript:** Lógica do jogo e manipulação do DOM.

## 📥 Como rodar o projeto localmente
1. Faça o clone deste repositório ou baixe os arquivos.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` para abrir no seu navegador.
